CANTUS DEI - VISUAL MUSICAL COMPLETO V2

Este pacote padroniza as páginas internas no mesmo estilo visual da
página principal.

INCLUÍDO

- Novo Grupo
- Integrantes
- Convites
- Momentos Litúrgicos
- Músicas
- Calendário
- Administração MASTER
- Aceite de convite
- Página pública da celebração
- GroupHeader
- CSS global

A aplicação passa a usar consistentemente:

- fundo escuro
- dourado
- tipografia editorial
- elementos musicais
- cards escuros/translúcidos
- botões arredondados
- formulários escuros
- navegação no mesmo padrão

COMO APLICAR

1. Extraia sobre:
D:\GitHub\cantus-dei

2. Execute:
npm run build

3. Se passar:
git add .
git commit -m "Padroniza todas as paginas no visual musical"
git push origin main

Não é necessário alterar banco, API ou variáveis de ambiente.
